# Дослідження ймовірностей сум при киданні двох кубиків



## Висновки (додано 2025-09-25 00:48:43)

- Проведено 1,000,000 симуляцій кидання двох кубиків. Отримані методом Монте-Карло ймовірності добре узгоджуються з аналітичними розрахунками.
- Максимальна відносна похибка серед сум: 1.04%.
- Висновок: симуляція реалізована коректно; оцінки ймовірностей збігаються з аналітичними розрахунками в межах статистичної похибки.
